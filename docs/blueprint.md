# **App Name**: Savigny IA

## Core Features:

- AI Chat & Text-to-Speech: Engage in text conversations with the AI via a WhatsApp-like interface. Includes a speaker button on AI messages for vocal playback.
- Hands-Free Voice Interaction: Utilize WebSpeech API for voice-to-text transcription, enabling hands-free spoken commands and queries to the AI.
- Dynamic API Configuration: User-configurable input fields on the homepage for 'Lien Cerveau' (AI Chat/Analysis API) and an optional 'Lien Médias' (Multimedia API) to link custom backends.
- Customizable AI Voice: A dropdown menu allowing users to select different system voices for the AI's spoken responses.
- Theme Toggle: A dedicated button to switch between a 'Mode Sombre' (Dark) and 'Mode Clair' (Light) theme for optimal viewing.
- Multimodal Content Upload Tool: Upload buttons for various file types including PDF, code, music, photos, and videos, enabling the AI tool to process diverse content formats.

## Style Guidelines:

- Color scheme is built for dark mode with easy adaptation to light mode via a toggle. The primary accent is a rich indigo (#5C5CDC), representing intelligence and clarity, providing strong contrast on a dark background. The main background for dark mode is a subtle, deep blue-gray (#15151D) with a hint of indigo, ensuring legibility and reduced eye strain. An energetic cyan-blue (#75B3EF) serves as an accent for calls to action and highlights, creating visual interest while maintaining an analogous relationship.
- Primary and body font: 'Inter', a neutral sans-serif for exceptional readability in chat dialogues and various content types. Code font: 'Source Code Pro', a monospaced sans-serif, for displaying code snippets with clarity.
- Use a clean, modern, and outline-based icon set. Icons should be clear and easily understandable for features like speaker button, upload functions, theme toggle, and settings.
- The main chat interface follows a 'WhatsApp-like' design with message bubbles and a persistent input field at the bottom. Configuration options are presented clearly, possibly within a settings screen or modal, for easy access to API links and voice selection. Overall layout is responsive for effective display across various mobile screen sizes within the WebView.
- Subtle, smooth transitions for theme changes (dark/light mode). Consider discreet animations for message sending and loading indicators when the AI is processing requests or content uploads, providing clear feedback to the user.
